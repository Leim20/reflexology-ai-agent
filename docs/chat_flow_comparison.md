```
┌─────────────────────────────────────────────────────────────────────────────┐

```

│                     目标：主动开启对话，引起兴趣                               │
└─────────────────────────────────────────────────────────────────────────────┘

❌ 当前做法 (被动):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

开场的关键原则：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 每次开场都要带一个问题，引导顾客说出需求
✅ 问题要简单、开放式，让顾客容易回答
✅ 语气轻松友好，不要太正式
❌ 不要只说 "Hi boss" 然后等待
❌ 不要问 "有什么可以帮你？"（太正式，太客服）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           STEP 2: 探需                                       │
│                     目标：找出顾客的需求/痛点                                 │
└─────────────────────────────────────────────────────────────────────────────┘

❌ 当前做法 (不探需):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
顾客: "有什么服务？"
AI:   [直接列出所有价格]  ← 没有了解需求，直接报价
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 期望做法 (先探需):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
顾客: "有什么服务？"
AI:   "我们有足部和身体按摩～请问您是想放松还是有哪里酸痛？"

│  运动/健身后 → 推荐: 身体按摩 + 拔罐                             │
│  开车/司机 → 推荐: 身体按摩（腰背）                              │
│                                                                 │

探需的关键原则：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 先问需求，再推荐（不要上来就报价）
✅ 一次只问一个问题
✅ 根据顾客回答，自动匹配推荐
✅ 如果顾客已经说出痛点，直接推荐（不用再问）
❌ 不要问太多问题（最多2个）
❌ 不要让顾客觉得像在做问卷
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 如何定义"难以搞定的顾客"？

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    难以搞定的顾客 = 触发电话预约的条件                         │
└─────────────────────────────────────────────────────────────────────────────┘

当以下 **任何一个** 条件满足时 → 提供店长电话让顾客直接打电话预约：

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【类型 1】明确表示嫌麻烦 (Explicit Complaints)
─────────────────────────────────────────────
关键词检测：
• "麻烦" / "好麻烦" / "太麻烦了" / "troublesome"
• "懒得填" / "不想填" / "don't want to fill"
• "能不能简单点" / "太复杂了" / "too complicated"

例子：
• 顾客: "哎呀好麻烦啊，要填这么多东西"
• 顾客: "Can simpler or not? So many things to fill"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【类型 2】拒绝提供资料 (Refuses to Share Info)
─────────────────────────────────────────────
关键词检测：
• "不想给" / "不想透露" / "don't want to share"
• "为什么要" / "why need" / "干嘛要电话"
• "隐私" / "privacy"
• 直接无视某些字段，只填部分资料

例子：
• 顾客: "为什么要我的电话号码？"
• 顾客: "不想给那么多资料"
• 顾客: [只填了名字和时间，其他空白]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【类型 3】主动要求打电话 (Requests Phone Booking)
─────────────────────────────────────────────
关键词检测：
• "可以打电话吗" / "can I call"
• "直接打电话" / "call directly"
• "电话预约" / "phone booking"
• "有没有电话" / "got phone number"

例子：
• 顾客: "可以直接打电话预约吗？"
• 顾客: "Got phone number? I call faster"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【类型 4】多次来回仍未完成 (Multiple Failed Attempts)
─────────────────────────────────────────────
行为检测：
• AI 发了预约模板后，顾客回复 ≥2 次仍未提供完整资料
• 顾客一直问问题但不填表
• 来回超过 3-4 轮还在纠结

例子：
• AI: [发模板]
• 顾客: "几点有位？"
• AI: "8点有位，请填写模板"
• 顾客: "那9点呢？"
• AI: "9点也有，请填写模板"
• 顾客: "那技师呢？有女的吗？"
• → 超过3轮，提供电话选项

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【类型 5】表现出不耐烦/frustration (Shows Frustration)
─────────────────────────────────────────────
关键词/语气检测：
• "算了" / "never mind" / "forget it"
• "..." / "???" (多个问号/省略号)
• "哎" / "唉" / "sigh"
• "烦" / "annoying"
• 语气变得简短/冷淡

例子：
• 顾客: "算了算了"
• 顾客: "..."
• 顾客: "ok nvm"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【类型 6】特殊要求超出AI能力 (Special Requests)
─────────────────────────────────────────────
情况：
• 要求团体预约 (>5人)
• 要求特殊折扣
• 要求指定某个技师号码
• 复杂的时间安排（多天、多时段）
• AI 无法确定的问题

例子：
• 顾客: "我们10个人，可以包场吗？"
• 顾客: "可以给我折扣吗？我是老顾客"
• 顾客: "我要预约星期一二三，每天不同时间"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
