PROBLEM

"Quota exceeded for quota metric 'Read requests' and limit 'Read requests per minute per user'"

- But NO production code actually called throttle_if_busy() or track_api_call()

- Result: Uncontrolled API calls → 429 errors

================================================================================
HOW IT WORKS
================================================================================

Before Each Google Sheets API Call:
1. throttle_if_busy() checks:
   - How many requests in last 60 seconds?
   - Is it >= 80% of 60-request quota?
   - If yes → Calculate wait time and pause
   - If no → Proceed immediately

2. Make the API call (append_row, update_cells, get_all_records, etc.)

3. track_api_call() records:
   - Time of this request
   - Adds to 60-second window counter

Result: System self-regulates to never exceed 60 requests/minute
